NDA-safe verification

When a client permits disclosure, evidence can include a client-approved testimonial, named case study, public project reference, redacted deliverable excerpt, sanitized technical artifact, or a third-party profile. When disclosure is prohibited, qualification can use private evidence appropriate to the engagement and confidentiality agreement.

Publicly verifiable

Published technical research, public tools, GitHub work, authorized public references, approved testimonials and third-party profiles.

Client-authorized

Named case studies, testimonials, project descriptions and outcome summaries released with explicit client permission.

Confidential

Private client identity, scope, architecture, vulnerabilities and deliverables that cannot ethically or contractually be exposed.

Important distinction

A list of countries is a representation of reported client experience; it is not itself independent proof. Dominion Fortress therefore treats independent proof as a separate evidence layer and will only publish claims that can be supported by the underlying source or client authorization.
