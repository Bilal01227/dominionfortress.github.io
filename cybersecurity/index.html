01 / SCOPE

Define objectives and permission

02 / ASSESS

Collect and validate evidence

Use agreed discovery and testing methods. Validate material findings and distinguish confirmed issues from observations or hypotheses.

Explain risk and next steps

Deliver evidence, impact, severity rationale, affected assets, recommended fixes and an ordered remediation plan.

Cybersecurity questions

Frequently asked questions.

What cybersecurity services does Dominion Fortress provide?

Our service directory covers authorized penetration testing, vulnerability assessment, web application security testing, API security testing, cloud security assessment, external attack surface assessment, red team testing and cybersecurity risk assessment.

What is the difference between vulnerability assessment and penetration testing?

A vulnerability assessment identifies and prioritizes weaknesses across a defined scope. Penetration testing uses controlled manual techniques to validate whether selected weaknesses can be exploited and what impact an attack path could have. The two services can complement one another.

Can you test a website, API or cloud environment remotely?

Remote delivery may be possible when the client can establish ownership or authorization, provide the required access and agree on scope, test windows and communication procedures.

Do you offer automated vulnerability patching?

DF Assurance is a prototype exploring AI-assisted vulnerability management and controlled remediation workflows. We do not claim that autonomous production patching is currently a generally available feature.

Will a security assessment guarantee that our systems are secure?

No assessment can guarantee that a system is free of vulnerabilities. Results are bounded by the agreed scope, access, test window, methods and evidence available at the time.

How do we get a cybersecurity proposal?

Describe the systems you own or are authorized to test, the business concern, preferred timeframe and any constraints through our project intake. We can then discuss an appropriate scope.
