Questions buyers ask about api security testing

What is broken object-level authorization (BOLA)?

BOLA occurs when an API fails to verify that the authenticated caller is permitted to access a specific object. It can expose or modify another user's or tenant's records.

Can you test REST and GraphQL APIs?

The assessment can cover REST and GraphQL interfaces when they are included in the agreed scope and the client provides the relevant documentation, endpoints and access.

Do you need API documentation?

OpenAPI or equivalent documentation helps accelerate mapping, but testing can also begin with approved endpoint information and access. Missing documentation is recorded as a scope limitation where relevant.
