Frequently asked questions

Can you work internationally?

Yes. Remote international engagements can be scoped where the required access, authorization and project conditions permit.

Do you provide a fixed package?

Scope depends on the systems, objectives and depth required. We prefer to size the engagement against the actual problem rather than sell unnecessary work.

Can I start with a smaller assessment?

Yes. A narrowly defined first engagement can be appropriate when you want to validate the risk, workflow or technical fit before expanding.

How is sensitive information handled?

Access and testing boundaries are agreed before authorized security work. Confidentiality requirements can be included in the engagement process.
